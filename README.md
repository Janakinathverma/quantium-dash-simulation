# Quantium Data Analytics - Pink Morsel Visualiser

This repository contains a data processing pipeline and an interactive dashboard built with Plotly Dash to analyze the impact of a price increase on "Pink Morsel" sales.

## 🚀 Features

- **Data Wrangling**: Automated cleaning of messy CSV data (stripping symbols, type casting).
- **Interactive UI**: Region-based filtering using Dash callbacks.
- **Modern Styling**: Custom CSS layout with a responsive design.
- **Testing**: Integrated test suite using Pytest.

## 🛠️ Setup & Execution

1. **Activate Environment:**
   - Windows: `.\venv\Scripts\activate`
   - Linux/Mac: `source venv/bin/activate`

2. **Install Dependencies:**

   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Dashboard:**

   ```bash
   python app.py
   ```

   Access at: <http://127.0.0.1:8050/>

## 📊 Insights

The visualization helps track sales trends before and after the price hike on January 15, 2021, providing clear business insights into customer price sensitivity.
